# 다니엘기도회 말씀 요약

다니엘기도회 21일 말씀을 [다글로](https://daglo.ai)로 정리한 보드를 연도별·회차별로 모아 보는 보기 전용 사이트입니다.

## 회차 추가하기

1. 다글로에서 공유로 복사한 내용을 `sermons.txt` 맨 아래에 그대로 붙여넣습니다.

   ```
   [2026 다니엘기도회 1일차 말씀] 김은호 목사 | 2026-11-01

   다글로에서 자세한 내용을 확인해 보세요
   https://daglo.ai/share/W8BwJ9nDJAW5mdi6
   ```

   다글로 링크가 들어 있는 줄만 읽으므로 링크만 한 줄씩 적어도 됩니다. `#` 으로 시작하는 줄은 무시합니다.

2. 커밋해서 올리면 GitHub가 내용을 가져와 사이트에 반영합니다. 내 컴퓨터에서 미리 보려면 빌드를 직접 실행합니다. (Node 20 이상, 설치할 패키지 없음)

   ```bash
   node scripts/build.mjs
   ```

새로 추가된 링크만 다글로에서 가져와 요약, 스크립트, 유튜브 썸네일을 `site/` 아래에 만들어 둡니다.

- 연도·일차·강사·날짜는 `sermons.txt` 에 적힌 글자가 아니라 다글로 보드의 실제 제목에서 읽습니다. 제목은 `[2026 다니엘기도회 1일차 말씀] 김은호 목사 | 2026-11-01` 형식이어야 합니다.
- 유튜브 주소는 다글로 보드에 들어 있는 것을 씁니다. 다른 영상을 쓰려면 다글로 링크와 같은 줄에 유튜브 링크를 함께 적습니다.
- 다글로에서 제목이나 내용을 고친 뒤 다시 받으려면 `node scripts/build.mjs --refresh` 를 실행합니다.

## 구성

| 경로 | 내용 |
| --- | --- |
| `sermons.txt` | 회차 목록. 회차를 추가할 때 고치는 유일한 파일 |
| `src/page.html` | 페이지 틀. 화면 구성이나 스타일을 바꿀 때 고침 |
| `scripts/build.mjs` | 다글로에서 내용을 가져와 사이트를 만드는 스크립트 |
| `cache/` | 다글로에서 받아 온 원본. 다시 받지 않도록 저장해 둠 |
| `site/` | 배포할 정적 사이트 |
| `site/app.js`, `site/logo.svg`, `site/og.jpg` | 화면 동작, 로고, 첫 화면 미리보기 이미지 |
| `site/index.html`, `site/2026/01/` 등, `site/data/`, `site/thumbs/` | 빌드가 만드는 파일. 직접 고치지 않음 |

회차마다 주소가 따로 있습니다 (예: `…/2026/01/`). 링크를 메신저에 붙였을 때 그 회차의 강사, 요약 제목, 썸네일이 미리보기로 뜨게 하기 위해서입니다. 미리보기에 쓰는 사이트 주소는 `scripts/build.mjs` 의 `SITE_URL` 에 있으니, 주소가 바뀌면 함께 고쳐 주세요.

내 컴퓨터에서 미리 보려면 `site/` 폴더를 간단한 서버로 띄웁니다.

```bash
npx serve site
```

다글로는 공유 페이지를 다른 사이트에 끼워 넣는 것(iframe)과 브라우저에서 요약을 직접 불러오는 것을 막고 있어서, 빌드할 때 내용을 미리 받아 사이트에 담는 방식을 씁니다.
