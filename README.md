# 다니엘기도회 말씀 노트

다니엘기도회 21일 말씀을 [다글로](https://daglo.ai)로 정리한 보드를 연도별·회차별로 모아 보는 보기 전용 사이트입니다.

## 회차 추가하기

1. `sermons.json` 에 다글로 공유 링크를 한 줄 추가합니다.

   ```json
   [
     { "daglo": "https://daglo.ai/share/W8BwJ9nDJAW5mdi6" },
     { "daglo": "https://daglo.ai/share/pPTG7kD2prnrKixj" }
   ]
   ```

2. 빌드를 실행합니다. (Node 20 이상, 설치할 패키지 없음)

   ```bash
   node scripts/build.mjs
   ```

새로 추가된 링크만 다글로에서 가져와 요약, 핵심 키워드, 스크립트, 유튜브 썸네일을 `site/` 아래에 만들어 둡니다.

- 연도·일차·강사·날짜는 다글로 보드 제목에서 읽습니다. 제목은 `[2026 다니엘기도회 1일차 말씀] 김은호 목사 | 2026-11-01` 형식이어야 합니다.
- 유튜브 주소는 다글로 보드에 들어 있는 것을 씁니다.
- 제목 형식이 다르거나 값을 바꾸고 싶으면 항목에 직접 적습니다: `"year"`, `"day"`, `"speaker"`, `"date"`, `"youtube"`.
- 다글로에서 내용을 고친 뒤 다시 받으려면 `node scripts/build.mjs --refresh` 를 실행합니다.

## 구성

| 경로 | 내용 |
| --- | --- |
| `sermons.json` | 회차 목록. 사람이 고치는 유일한 파일 |
| `scripts/build.mjs` | 다글로에서 내용을 가져와 사이트 데이터를 만드는 스크립트 |
| `cache/` | 다글로에서 받아 온 원본. 다시 받지 않도록 저장해 둠 |
| `site/` | 배포할 정적 사이트. `index.html` 을 브라우저로 열면 바로 보임 |
| `site/data/`, `site/thumbs/` | 빌드가 만드는 파일 |

다글로는 공유 페이지를 다른 사이트에 끼워 넣는 것(iframe)과 브라우저에서 요약을 직접 불러오는 것을 막고 있어서, 빌드할 때 내용을 미리 받아 사이트에 담는 방식을 씁니다.
